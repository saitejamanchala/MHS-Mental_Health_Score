# 🧠 Mental Health Score Prediction System

An end-to-end Machine Learning solution designed to analyze psychometric, demographic, and behavioral metrics to predict and quantify mental health scores for proactive wellness assessment.

🚀 **Live Demo:** [Try the Mental Health Score Predictor](https://mhs-mental-health-score.onrender.com)

---

### 📌 Project Highlights
* **Predictive Modeling:** Built and evaluated robust ML models to accurately assess mental health risk scores based on user survey input.
* **Feature Engineering:** Preprocessed high-dimensional behavioral features, applied scaling, and resolved missing values without data leakage.
* **Microservice Backend:** Powered by a low-latency FastAPI backend deployed on Render for real-time model inference.
* **Data-Driven Insights:** Integrated statistical feature selection to isolate key psychometric stressors and behavioral indicators.

---

### 🛠️ Tech Stack
* **Language:** Python
* **Machine Learning:** Scikit-Learn, Pandas, NumPy
* **API Framework:** FastAPI / Uvicorn
* **Deployment:** Render
